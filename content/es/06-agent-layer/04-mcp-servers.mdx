## Qué es MCP

El Model Context Protocol es un estándar abierto para conectar herramientas de IA con fuentes de datos externas ([Claude Code: Overview](https://code.claude.com/docs/en/overview)). Un servidor MCP expone herramientas que el agente puede llamar, como las de lectura de Figma que viste en [Comprobar con el MCP](/figma/verify-with-mcp).

## El servidor de Figma

Figma recomienda el servidor remoto, en `https://mcp.figma.com/mcp`: no necesita la aplicación de escritorio y tiene el conjunto de funciones más amplio. El servidor de escritorio queda para necesidades concretas de organizaciones ([Figma: Figma MCP server](https://help.figma.com/hc/en-us/articles/32132100833559)).

Hay tres formas de conectarlo a Claude Code. Figma documenta dos ([Figma: Remote server installation](https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/)):

**Con el plugin de Figma (recomendada).** Instala el servidor y las skills de Figma:

```bash filename="Terminal"
claude plugin install figma@claude-plugins-official
```

Después, reinicia Claude Code, abre `/plugin`, ve a la pestaña **Installed**, elige `figma` y sigue el inicio de sesión en el navegador con **Allow access**.

**A mano.** Añade solo el servidor, sin las skills:

```bash filename="Terminal"
claude mcp add --transport http figma https://mcp.figma.com/mcp
```

Después, en una sesión nueva, abre `/mcp`, elige **figma** y **Authenticate**.

La tercera la documenta Claude Code ([Claude Code: MCP](https://code.claude.com/docs/en/mcp#use-mcp-servers-from-claude-ai)):

**Con el conector de claude.ai.** Si iniciaste sesión en Claude Code con tu cuenta de claude.ai, los servidores que conectaste en claude.ai, llamados conectores, aparecen solos en Claude Code. Conecta Figma en [claude.ai/customize/connectors](https://claude.ai/customize/connectors) (en Team y Enterprise, solo los administradores añaden servidores) y completa allí el inicio de sesión. En `/mcp`, los conectores aparecen marcados como de claude.ai.

Claude Code solo carga los conectores cuando la autenticación activa es la cuenta de claude.ai. Con `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN` o `apiKeyHelper` activos no los carga, aunque hayas hecho `/login`. Si `/mcp` no muestra Figma, mira con `/status` qué autenticación está activa.

Si además tienes Figma con el plugin o a mano, Claude Code se conecta una sola vez: manda el servidor de Claude Code y `/mcp` muestra el conector como oculto.

## El servidor de Storybook

Con el servidor de desarrollo de Storybook en marcha y el addon instalado ([Storybook y su MCP](/design-to-code/storybook-mcp)), el servidor está en `http://localhost:6006/mcp`. Se añade a Claude Code igual que cualquier servidor HTTP ([Claude Code: MCP](https://code.claude.com/docs/en/mcp)):

```bash filename="Terminal"
claude mcp add --transport http storybook http://localhost:6006/mcp
```

## Compartir la configuración con el equipo

Claude Code guarda cada servidor en uno de tres ámbitos ([Claude Code: MCP](https://code.claude.com/docs/en/mcp)):

| Ámbito | Dónde se guarda | Se comparte |
|---|---|---|
| Local (por defecto) | `~/.claude.json`, para el proyecto actual | No |
| Proyecto | `.mcp.json`, en la raíz del repositorio | Sí, con el control de versiones |
| Usuario | `~/.claude.json`, para todos tus proyectos | No |

Con `--scope project`, el servidor queda en `.mcp.json` y todo el equipo lo tiene al clonar el repositorio. Por seguridad, Claude Code pide aprobación antes de usar los servidores de un `.mcp.json`.

```bash filename="Terminal"
claude mcp add --transport http storybook --scope project http://localhost:6006/mcp
```

<Callout variant="recommendation">

En el repositorio del sistema de diseño, guarda Storybook en el ámbito de proyecto, porque es parte del repositorio. El de Figma, con el plugin, en el ámbito de usuario o con el conector: cada persona inicia sesión con su propia cuenta de Figma. Si ya usas Figma en claude.ai, el conector te ahorra otra conexión; si quieres también las skills de Figma, instala el plugin.

</Callout>

<Takeaways>

## En resumen

- El servidor MCP de Figma da acceso en vivo a diseños, variables y Code Connect; el de Storybook, a componentes y props.
- Figma recomienda el servidor remoto, instalado con el plugin de Figma para tener también sus skills; con una cuenta de claude.ai, también llega como conector.
- El ámbito de proyecto guarda la configuración en `.mcp.json` para todo el equipo.

</Takeaways>
