En esta práctica montas la capa de agente sobre el repositorio del piloto: el archivo de instrucciones, dos skills, los servidores MCP y, si tu plan lo permite, el sistema publicado en Claude.

## Qué necesitas

- El repositorio con `docs/` de la [práctica del capítulo 4](/documentation/practice-component-doc).
- Claude Code instalado ([Requisitos](/start-here/requirements)).

## Pasos

1. Escribe `AGENTS.md` con la [plantilla](/agent-layer/claude-md#la-plantilla), adaptada a tu sistema. Cuenta las líneas: menos de 200.
2. Crea `CLAUDE.md` con `@AGENTS.md` y lo propio de Claude Code.
3. Crea las skills `build-ui` y `review-ui` en `.claude/skills/` ([Skills](/agent-layer/skills)).
4. Conecta el servidor MCP de Figma con el plugin y, si usas Storybook, el de Storybook en el ámbito de proyecto ([Servidores MCP](/agent-layer/mcp-servers)).
5. Si tu plan lo permite, crea el sistema en Claude con `/design-sync` y publícalo ([Claude Design](/agent-layer/claude-design)).
6. Opcional: crea un Project para el equipo con los documentos del sistema ([Projects de Claude](/agent-layer/claude-projects)).

## Una primera prueba

Pide a Claude Code una de las pantallas de tu piloto, sin más contexto:

```text filename="Prompt de prueba"
Crea la pantalla de inicio de sesión de la aplicación.
```

Mira qué hace: si abre `docs/patterns/`, si usa los componentes del sistema, si usa tokens y no valores. Lo que falle te dice qué falta en `AGENTS.md` o en la skill. En el capítulo 7 conviertes esta prueba en un método.

## Cómo saber si está bien

- `AGENTS.md` tiene menos de 200 líneas y enlaza a `docs/` en lugar de copiarla.
- `/build-ui` y `/review-ui` aparecen como skills en Claude Code.
- `/mcp` muestra Figma conectado y, si lo usas, Storybook.
- La pantalla de prueba usa el patrón documentado.

<Takeaways>

## En resumen

- Tienes `AGENTS.md` y `CLAUDE.md` con las reglas que valen siempre y el mapa de `docs/`.
- Tienes skills para crear y revisar interfaces, y los servidores MCP conectados.
- Has hecho una primera prueba y sabes qué ajustar.

</Takeaways>
