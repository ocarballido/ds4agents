## El contexto es un recurso limitado

Anthropic describe el contexto de un agente como un recurso finito con rendimientos decrecientes: a medida que se llena, la capacidad del modelo de recordar con precisión lo que contiene disminuye ([Anthropic: Effective context engineering for AI agents](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)). Por eso propone que los agentes mantengan referencias ligeras, como rutas de archivo, y carguen los datos en el momento en que los necesitan. Llama a eso divulgación progresiva.

Para un sistema de diseño, la consecuencia es clara: el agente no tiene que leer los cuarenta documentos de componentes al empezar. Tiene que saber que existen, dónde están y cuándo abrir cada uno.

Claude Code carga los archivos `CLAUDE.md` al empezar cada sesión ([Claude Code: Memory](https://code.claude.com/docs/en/memory)). Las skills se cargan cuando la petición coincide con su descripción, o cuando se invocan con `/nombre` ([Claude Code: Skills](https://code.claude.com/docs/en/skills)). Las reglas de `.claude/rules/` con un campo `paths` se cargan solo cuando Claude trabaja con archivos que coinciden ([Claude Code: Memory](https://code.claude.com/docs/en/memory)).

## Las piezas de la capa de agente

| Pieza | Qué lleva | Página |
|---|---|---|
| `CLAUDE.md` o `AGENTS.md` | Reglas no negociables, mapa de `docs/`, comandos | [CLAUDE.md y AGENTS.md](/agent-layer/claude-md) |
| Skills | Procedimientos de varios pasos: crear una pantalla, revisar una interfaz | [Skills](/agent-layer/skills) |
| Servidores MCP | Acceso en vivo a Figma y Storybook | [Servidores MCP](/agent-layer/mcp-servers) |
| Sistema de diseño en Claude | Un artifact que Claude Design aplica en los chats, en Artifacts y en Claude Code | [Sistemas de diseño en Claude](/agent-layer/claude-design) |
| Project de Claude | El sistema para consultas del equipo | [Projects de Claude](/agent-layer/claude-projects) |

<Callout variant="recommendation">

Antes de escribir una línea en `CLAUDE.md`, pregúntate si el agente la necesita en **todas** las sesiones. Si solo la necesita para una tarea, va a una skill. Si solo para un tipo de archivo, a una regla por ruta. Si es el detalle de un componente, a su documento en `docs/`.

</Callout>

<Takeaways>

## En resumen

- El contexto es limitado: el agente carga lo mínimo y abre el resto cuando lo necesita.
- `CLAUDE.md` se carga siempre; skills y reglas por ruta, bajo demanda; los MCP, en vivo.
- Cada pieza de información va al momento de carga que le corresponde.

</Takeaways>
