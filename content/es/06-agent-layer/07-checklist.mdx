## El entregable

- `AGENTS.md`, con las reglas que valen siempre y el mapa de `docs/`, y `CLAUDE.md` que lo importa.
- Las skills `build-ui` y `review-ui` en `.claude/skills/`.
- Los servidores MCP de Figma y, si lo usas, de Storybook, conectados.
- Si tu plan lo permite, el sistema de diseño en Claude y un Project para el equipo.

## Pasos

1. Escribe `AGENTS.md` con la [plantilla](/agent-layer/claude-md#la-plantilla), adaptada a tu sistema.
2. Crea `CLAUDE.md` con `@AGENTS.md` y lo propio de Claude Code.
3. Crea las skills de crear y revisar interfaces ([Skills](/agent-layer/skills)).
4. Conecta el servidor MCP de Figma con el plugin y el de Storybook en el ámbito de proyecto ([Servidores MCP](/agent-layer/mcp-servers)).
5. Si tu plan lo permite, crea el sistema de diseño en Claude con `/design-sync` y pruébalo con los patrones del piloto ([Sistemas de diseño en Claude](/agent-layer/claude-design)).
6. Si el equipo lo necesita, crea un Project con los documentos del sistema ([Projects de Claude](/agent-layer/claude-projects)).

## Una primera prueba

Pide a Claude Code una de las pantallas de tu piloto, sin más contexto:

```text filename="Prompt de prueba"
Crea la pantalla de inicio de sesión de la aplicación.
```

Mira qué hace: si abre `docs/patterns/`, si usa los componentes del sistema, si usa tokens y no valores. Lo que falle indica qué falta en `AGENTS.md` o en la skill. El [capítulo 7](/evaluation/why-evaluate) convierte esta prueba en un método.

## Criterios para darlo por terminado

- `AGENTS.md` tiene menos de 200 líneas y enlaza a `docs/` en lugar de copiarla.
- `/build-ui` y `/review-ui` aparecen como skills en Claude Code.
- `/mcp` muestra Figma conectado y, si lo usas, Storybook.
- La pantalla de prueba usa el patrón documentado.

<Takeaways>

## En resumen

- El entregable es el archivo de instrucciones, dos skills, los servidores MCP y el sistema de diseño en Claude.
- `AGENTS.md` enlaza a la documentación en lugar de copiarla.
- Una primera prueba dice qué ajustar antes de evaluar con método.
