## La estructura completa del repositorio

Al terminar las siete fases, el repositorio del sistema queda así:

```text filename="Repositorio del sistema de diseño"
AGENTS.md                  reglas para cualquier agente
CLAUDE.md                  @AGENTS.md y lo propio de Claude Code
CHANGELOG.md
CONTRIBUTING.md
.mcp.json                  servidores MCP compartidos (Storybook)
.claude/
├── rules/                 reglas por ruta
└── skills/                build-ui y review-ui
docs/
├── inventory.md
├── foundations/
├── components/
├── patterns/
├── content/
└── rules/
tokens/                    DTCG, exportados de Figma
src/components/            componentes, historias y plantillas de Code Connect
evals/evals.md
scripts/                   build-figma-guidelines, validate-docs, check-ui
figma.config.json
```

## En resumen

- Cada plantilla está en la página que explica su porqué; este índice las reúne por fase.
- Las plantillas cubren documentos, scripts, configuración e instrucciones para agentes.
- Al final, el repositorio reúne todo lo que leen las personas y los agentes.
