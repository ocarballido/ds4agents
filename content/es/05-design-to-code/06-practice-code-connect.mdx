En esta práctica conectas los componentes del piloto con su código, les añades instrucciones para el MCP y compruebas que el agente recibe el componente real.

## Qué necesitas

- Figma Professional o superior, con asiento Full o Dev ([Requisitos](/start-here/requirements)).
- La ruta de cada componente del piloto en el repositorio.
- Los documentos de los componentes del [capítulo 4](/documentation/practice-component-doc).

## Pasos

1. Conecta cada componente del piloto en Code Connect UI ([Mapear propiedades](/design-to-code/mapping-props#conectar-en-code-connect-ui)).
2. Añade a cada uno sus instrucciones para el MCP, resumidas desde la sección Reglas de su documento ([Instrucciones para el MCP](/design-to-code/mcp-instructions)).
3. En un marco que use varios componentes del piloto, pide al agente `get_code_connect_map` y revisa que cada instancia trae su componente, su ruta y su fragmento ([Comprobar con el MCP](/figma/verify-with-mcp)).
4. Si usas Storybook con React: instala el MCP, activa el manifiesto y añade `@summary` al componente más usado del piloto ([Storybook y su MCP](/design-to-code/storybook-mcp)).
5. Actualiza la columna Code Connect de `inventory.md`.

## Cómo saber si está bien

- `get_code_connect_map` devuelve el componente de código de cada instancia del piloto.
- El fragmento importa desde la ruta correcta.
- Las instrucciones aparecen en la respuesta del servidor MCP junto al fragmento.
- Si usas Storybook, `docs-show` devuelve las props del componente con sus descripciones.

<Takeaways>

## En resumen

- Los componentes del piloto están conectados con su código.
- Cada conexión lleva las reglas que más errores evitan al implementar.
- Has comprobado que el agente recibe el componente real y sus reglas.

</Takeaways>
