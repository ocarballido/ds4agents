## El entregable

- Los componentes del alcance conectados con Code Connect, cada uno con sus reglas para el agente: con Code Connect UI, sus instrucciones para el MCP; con archivos de plantilla, la descripción del componente con su enlace a `docs/` ([Instrucciones para el MCP](/design-to-code/mcp-instructions#con-archivos-de-plantilla)).
- Si usas Storybook con React: el servidor MCP instalado, el manifiesto activado y `@summary` en los componentes del alcance.
- La columna Code Connect de `inventory.md` al día.

Code Connect pide Figma Professional o superior, con asiento Full o Dev ([Requisitos](/start-here/requirements)). En Professional, la primera publicación fija la librería y el framework activos ([Code Connect](/design-to-code/code-connect#requisitos)).

## Pasos

1. Conecta cada componente en Code Connect UI ([Mapear propiedades](/design-to-code/mapping-props#conectar-en-code-connect-ui)), o con un archivo de plantilla si necesitas fragmentos exactos.
2. Con Code Connect UI, añade a cada conexión sus instrucciones para el MCP, resumidas desde la sección Reglas de su documento ([Instrucciones para el MCP](/design-to-code/mcp-instructions)). Con archivos de plantilla, que no tienen instrucciones, comprueba que la descripción de cada componente lleva sus reglas y la línea `Docs:` ([Descripciones](/figma/descriptions#una-plantilla-de-cinco-líneas)).
3. En un marco con varios componentes del alcance, pide `get_code_connect_map` y revisa cada instancia ([Comprobar con el MCP](/figma/verify-with-mcp)).
4. Pide también `get_code_connect_map` de un marco o una pantalla completos, no solo de cada componente, y revisa que no aparezcan componentes de código que no esperas. En nuestra prueba con el servidor MCP remoto (22 de octubre de 2026) aparecieron iconos sueltos dentro de componentes no conectados.
5. Si usas Storybook: instala el MCP, activa el manifiesto y escribe el JSDoc ([Storybook y su MCP](/design-to-code/storybook-mcp), [JSDoc para agentes](/design-to-code/jsdoc)).
6. Actualiza `inventory.md`.

## Criterios para darlo por terminado

- `get_code_connect_map` devuelve el componente de código de cada instancia del alcance.
- El fragmento importa desde la ruta correcta.
- Las reglas llegan al agente: con Code Connect UI, las instrucciones aparecen en la respuesta del servidor MCP junto al fragmento; con archivos de plantilla, `get_design_context` devuelve la descripción del componente con su enlace a `docs/`.
- Si usas Storybook, `docs-show` devuelve las props del componente con sus descripciones.

<Takeaways>

## En resumen

- El entregable son componentes conectados con su código, cada uno con sus reglas para el agente.
- Storybook añade las props y los ejemplos de uso si trabajas con React.
- La fase está terminada cuando el MCP devuelve el componente real y sus reglas: las instrucciones o la descripción con su enlace a `docs/`.

</Takeaways>
